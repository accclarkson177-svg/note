    下面从 C 语言学习者的角度，系统对比 Python 和 C 语言的常见语法与概念差异，包括：变量、数组/列表/元组/字典、指针、循环、字符串、函数、宏、主函数等。

    1. 整体区别¶

    对比项 C 语言 Python
    类型系统 静态类型，变量声明时确定类型 动态类型，运行时确定类型
    编译/解释 编译型语言 解释型语言
    语句块 用 {} 表示代码块 用缩进表示代码块
    行结束 通常用 ; 通常不用 ;
    内存管理 手动管理较多，如 malloc/free 自动垃圾回收
    指针 有显式指针和地址操作 没有 C 风格指针
    运行入口 main() 函数 通常用 if __name__ == "__main__":

    2. 变量定义¶

    C 语言¶

    C 语言需要先声明变量类型：

    int a = 10;
double b = 3.14;
char c = 'A';

    变量类型固定：

    int x = 10;
x = 3.14;  // 会发生类型转换，可能丢失精度

    Python¶

    Python 不需要声明类型：

    a = 10
b = 3.14
c = "A"

    变量本质上是“名字”绑定到对象：

    x = 10
x = 3.14
x = "hello"

    这是允许的。

    对比¶

    项目 C Python
    是否需要声明类型 需要 不需要
    变量类型能否改变 一般不能 可以
    示例 int a = 10; a = 10

char ch = 'A';

    Python 常见类型¶

    例如：

    4. 代码块：大括号 vs 缩进¶

    C 语言¶

    if (x > 0) {
    printf("positive\n");
}

    C 用 {} 表示代码块。

    Python¶

    if x > 0:
    print("positive")

    Python 用缩进表示代码块。

    错误示例：

    if x > 0:
print("positive")  # 缩进错误

    5. 数组、列表、元组、字典¶

    这是 C 转 Python 时最重要的一部分。

    5.1 C 数组¶

    int arr[5] = {1, 2, 3, 4, 5};

    特点：

    1. 长度固定
    2. 类型固定
    3. 内存连续
    4. 用下标访问
    printf("%d\n", arr[0]);

    5.2 Python 列表 list¶

    Python 中最接近 C 数组的是 列表 list：

    arr = [1, 2, 3, 4, 5]

    访问元素：

    print(arr[0])

    修改元素：

    arr[0] = 100

    添加元素：

    arr.append(6)

    删除元素：

    arr.remove(3)

    C 数组 vs Python list¶

    对比项 C 数组 Python list
    长度 通常固定 可变
    类型 一般统一 可混合
    访问方式 下标 下标
    是否可修改 可以 可以
    内存 连续存储具体数据 存对象引用

    Python 列表可以混合类型：

    a = [1, "hello", 3.14, True]

    而 C 数组通常不能这样：

    int a[3] = {1, 2, 3};

    5.3 Python 元组 tuple¶

    元组类似“不可修改的列表”。

    t = (1, 2, 3)

    访问：

    print(t[0])

    不能修改：

    t[0] = 100  # 报错

    元组可以理解为 C 里的只读数组¶

    类似：

    const int arr[3] = {1, 2, 3};

    但只是类比，并不完全等价。

    5.4 Python 字典 dict¶

    字典是键值对结构：

    student = {
    "name": "张三",
    "age": 18,
    "score": 95
}

    访问：

    print(student["name"])
print(student["age"])

    修改：

    student["age"] = 19

    新增：

    student["city"] = "北京"

    字典类似什么？¶

    在 C 中可以类比：

    1. 哈希表
    2. 结构体
    3. 键值映射表

    例如 C 结构体：

    struct Student {
    char name[20];
    int age;
    int score;
};

    Python 字典：

    student = {
    "name": "Tom",
    "age": 18,
    "score": 90
}

    区别是：

    • C 结构体字段固定
    • Python 字典可以动态增加键值

    5.5 Python 集合 set¶

    集合用于存储不重复元素：

    s = {1, 2, 3, 3, 3}
print(s)  # {1, 2, 3}

    集合特点：

    1. 无序
    2. 不重复
    3. 不能通过下标访问

    集合运算：

    a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)  # 并集
print(a & b)  # 交集
print(a - b)  # 差集

    6. Python 中有没有数组？¶

    严格来说，Python 内置最常用的是 list，但它不是 C 那种原生数组。

    如果你想用更接近 C 数组的结构，可以用：

    6.1 array 模块¶

    from array import array

a = array('i', [1, 2, 3, 4])

    这里 'i' 表示整数类型。

    6.2 NumPy 数组¶

    科学计算中常用：

    import numpy as np

a = np.array([1, 2, 3, 4])

    NumPy 数组更接近 C 的数组：

    • 类型统一
    • 存储紧凑
    • 运算速度快
    • 支持矩阵运算

    7. 指针与地址¶

    这是 C 和 Python 最大的差异之一。

    7.1 C 语言指针¶

    C 中可以取地址：

    int a = 10;
int *p = &a;

    访问指针指向的值：

    printf("%d\n", *p);

    修改：

    *p = 20;

    此时：

    a == 20

    7.2 Python 没有 C 风格指针¶

    Python 不能这样写：

    p = &a   # 错误
*p = 20 # 错误

    Python 没有：

    &
*

    这种地址和解引用操作。

    7.3 Python 中的变量更像“引用”¶

    Python 变量可以理解为“名字指向对象”。

    a = [1, 2, 3]
b = a

    这时 a 和 b 指向同一个列表。

    b[0] = 100
print(a)  # [100, 2, 3]

    因为它们引用的是同一个对象。

    7.4 Python 查看对象身份¶

    Python 可以用 id() 查看对象标识：

    a = [1, 2, 3]
b = a

print(id(a))
print(id(b))

    如果相同，说明它们指向同一个对象。

    但注意：

    id() 不是给你做 C 指针运算用的地址。

    7.5 可变对象与不可变对象¶

    Python 中很重要的概念是：

    类型 是否可变
    int 不可变
    float 不可变
    str 不可变
    tuple 不可变
    list 可变
    dict 可变
    set 可变

    例如：

    a = 10
b = a
b = 20

print(a)  # 10

    因为整数不可变，b = 20 是让 b 指向新对象，不影响 a。

    但是：

    a = [1, 2, 3]
b = a
b[0] = 100

print(a)  # [100, 2, 3]

    列表可变，所以修改内容会影响所有引用它的变量。

    8. 循环：for 和 while¶

    8.1 while 循环¶

    C 语言¶

    int i = 0;

while (i < 5) {
    printf("%d\n", i);
    i++;
}

    Python¶

    i = 0

while i < 5:
    print(i)
    i += 1

    区别：

    • Python 条件后面要加 :
    • Python 没有 i++
    • Python 使用缩进表示循环体

    8.2 for 循环¶

    C 语言¶

    for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}

    Python¶

    Python 的 for 更像“遍历”：

    for i in range(5):
    print(i)

    range(5) 产生：

    0, 1, 2, 3, 4

    如果想从 1 到 5：

    for i in range(1, 6):
    print(i)

    如果想步长为 2：

    for i in range(0, 10, 2):
    print(i)

    输出：

    0
2
4
6
8

    8.3 遍历数组/列表¶

    C 语言¶

    int arr[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++) {
    printf("%d\n", arr[i]);
}

    Python¶

    arr = [10, 20, 30, 40, 50]

for x in arr:
    print(x)

    如果需要下标：

    for i, x in enumerate(arr):
    print(i, x)

    8.4 break 和 continue¶

    C 和 Python 都有：

    C¶

    for (int i = 0; i < 10; i++) {
    if (i == 5) break;
    if (i == 2) continue;
    printf("%d\n", i);
}

    Python¶

    for i in range(10):
    if i == 5:
        break
    if i == 2:
        continue
    print(i)

    9. 条件语句¶

    C 语言¶

    if (x > 0) {
    printf("positive\n");
} else if (x == 0) {
    printf("zero\n");
} else {
    printf("negative\n");
}

    Python¶

    if x > 0:
    print("positive")
elif x == 0:
    print("zero")
else:
    print("negative")

    注意：

    • Python 是 elif
    • 不是 else if
    • 条件后面加 :
    • 不用 {}

    10. 字符串操作¶

    10.1 C 字符串¶

    C 字符串本质是字符数组，以 '\0' 结尾：

    char s[] = "hello";

    字符串函数需要头文件：

    #include <string.h>

    常见操作：

    strlen(s);
strcpy(dest, src);
strcmp(a, b);
strcat(a, b);

    10.2 Python 字符串¶

    Python 字符串是 str 对象：

    s = "hello"

    长度：

    len(s)

    访问字符：

    s[0]  # 'h'

    切片：

    s[1:4]  # 'ell'

    拼接：

    s = "hello" + " world"

    查找：

    s.find("lo")

    替换：

    s.replace("hello", "hi")

    分割：

    "192.168.1.1".split(".")

    结果：

    ["192", "168", "1", "1"]

    10.3 Python 字符串不可修改¶

    s = "hello"
s[0] = "H"  # 报错

    正确做法：

    s = "H" + s[1:]
print(s)  # Hello

    10.4 格式化输出¶

    C¶

    printf("age = %d, score = %.2f\n", age, score);

    Python¶

    推荐 f-string：

    print(f"age = {age}, score = {score:.2f}")

    11. 函数¶

    11.1 C 语言函数¶

    int add(int a, int b) {
    return a + b;
}

    调用：

    int result = add(3, 5);

    11.2 Python 函数¶

    def add(a, b):
    return a + b

    调用：

    result = add(3, 5)

    对比¶

    项目 C Python
    定义关键字 无，直接写返回类型 def
    参数类型 通常要写 不写
    返回类型 通常要写 不写
    代码块 {} 缩进
    返回 return return

    11.3 Python 函数可以返回多个值¶

    Python 可以这样：

    def calc(a, b):
    return a + b, a - b, a * b

    接收：

    x, y, z = calc(10, 3)

    实际上返回的是一个元组：

    (13, 7, 30)

    C 中如果想返回多个值，通常需要：

    1. 使用指针参数
    2. 使用结构体
    3. 使用数组

    例如 C 里用指针返回多个结果：

    void calc(int a, int b, int *sum, int *diff) {
    *sum = a + b;
    *diff = a - b;
}

    12. 函数参数传递差异¶

    C 语言¶

    C 默认是值传递：

    void change(int x) {
    x = 100;
}

int main() {
    int a = 10;
    change(a);
    printf("%d\n", a); // 10
}

    如果要修改外部变量，需要指针：

    void change(int *x) {
    *x = 100;
}

    Python¶

    Python 传递的是“对象引用”。

    对于不可变对象：

    def change(x):
    x = 100

a = 10
change(a)
print(a)  # 10

    对于可变对象：

    def change(lst):
    lst[0] = 100

a = [1, 2, 3]
change(a)
print(a)  # [100, 2, 3]

    所以可以简单理解为：

    Python 不能通过给参数重新赋值来改变外部变量，但可以修改传入的可变对象内部内容。

    13. 主函数 main¶

    C 语言¶

    C 程序通常从 main() 开始执行：

    #include <stdio.h>

int main() {
    printf("Hello\n");
    return 0;
}

    Python¶

    Python 没有强制的 main() 函数。

    最简单的 Python 文件：

    print("Hello")

    直接运行就会执行。

    Python 常见主入口写法¶

    def main():
    print("Hello")

if __name__ == "__main__":
    main()

    含义：

    • 当这个文件被直接运行时，执行 main()
    • 当这个文件被其他文件导入时，不自动执行 main()

    例如：

    if __name__ == "__main__":
    main()

    可以理解为 Python 里的“程序入口保护”。

    14. 头文件、include 和 import¶

    C 语言¶

    #include <stdio.h>
#include <string.h>

    #include 是预处理阶段把头文件内容包含进来。

    Python¶

    Python 使用 import 导入模块：

    import math

print(math.sqrt(16))

    也可以：

    from math import sqrt

print(sqrt(16))

    区别：

    C Python
    #include <stdio.h> import math
    预处理包含文件 导入模块对象
    编译前处理 运行时导入

    15. 宏 macro¶

    C 语言宏¶

    C 有预处理器：

    #define PI 3.14159
#define SQUARE(x) ((x) * (x))

    使用：

    double area = PI * r * r;
int y = SQUARE(5);

    宏是在编译前进行文本替换。

    Python 没有 C 语言这种宏¶

    Python 中一般用：

    1. 常量变量代替宏常量¶

    PI = 3.14159

    Python 没有真正的常量限制，但习惯上用全大写表示常量。

    2. 函数代替函数宏¶

    C：

    #define SQUARE(x) ((x) * (x))

    Python：

    def square(x):
    return x * x

    3. 条件编译¶

    C：

    #ifdef DEBUG
printf("debug mode\n");
#endif

    Python 没有完全相同的预处理条件编译，一般用普通变量：

    DEBUG = True

if DEBUG:
    print("debug mode")

    || or
    ! not

    Python：

    if a > 0 and b > 0:

    20. 内存分配¶

    C¶

    C 中可以手动分配和释放内存：

    int *p = malloc(sizeof(int) * 10);
free(p);

    如果忘记 free，可能内存泄漏。

    如果访问非法地址，可能段错误。

    Python¶

    Python 通常不需要手动释放：

    a = [1, 2, 3]

    当对象没有引用时，Python 会自动回收。

    但是 Python 不是完全不需要关心资源，比如文件要关闭：

    f = open("a.txt", "r")
data = f.read()
f.close()

    更推荐：

    with open("a.txt", "r") as f:
    data = f.read()

    with 会自动关闭文件。

    21. 异常处理¶

    C 通常用返回值表示错误：

    FILE *fp = fopen("a.txt", "r");
if (fp == NULL) {
    printf("open failed\n");
}

    Python 使用异常：

    try:
    f = open("a.txt", "r")
    data = f.read()
except FileNotFoundError:
    print("文件不存在")
finally:
    f.close()

    更常见：

    try:
    with open("a.txt", "r") as f:
        data = f.read()
except FileNotFoundError:
    print("文件不存在")

    23. 一个完整例子对比¶

    C 语言版本¶

    #include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main() {
    int nums[5] = {1, 2, 3, 4, 5};
    int sum = 0;

    for (int i = 0; i < 5; i++) {
        sum = add(sum, nums[i]);
    }

    printf("sum = %d\n", sum);

    return 0;
}

    Python 版本¶

    def add(a, b):
    return a + b

def main():
    nums = [1, 2, 3, 4, 5]
    total = 0

    for x in nums:
        total = add(total, x)

    print(f"sum = {total}")

if __name__ == "__main__":
    main()

    24. 从 C 转 Python 最需要注意的点¶

    1. 不用写类型¶

    C：

    int x = 10;

    Python：

    x = 10

    2. 不用分号¶

    C：

    printf("hello\n");

    Python：

    print("hello")

    3. 不用大括号，用缩进¶

    C：

    if (x > 0) {
    printf("ok\n");
}

    Python：

    if x > 0:
    print("ok")

    4. 没有指针，但有引用¶

    C：

    int *p = &a;

    Python 没有这种写法。

    但：

    a = [1, 2, 3]
b = a

    a 和 b 引用同一个列表。

    5. Python 的 for 是遍历式¶

    C：

    for (int i = 0; i < n; i++)

    Python：

    for i in range(n):
    ...

    遍历列表：

    for item in arr:
    ...

    6. Python 字符串、元组、整数不可变¶

    s = "hello"
s[0] = "H"  # 错误

    7. Python 列表、字典、集合可变¶

    a = [1, 2, 3]
a[0] = 100

d = {"name": "Tom"}
d["age"] = 18

    25. 最后总结¶

    如果用一句话概括：

    C 更接近底层，强调类型、内存、指针和编译；Python 更接近高级抽象，强调简洁、动态类型、容器和快速开发。

    从 C 语言转 Python，可以这样记：

    C 数组        -> Python list / array / numpy array
C 只读数组    -> Python tuple
C 结构体      -> Python dict / class
C 指针        -> Python 没有显式指针，但变量是对象引用
C #define     -> Python 常量变量或函数
C main        -> Python 的 if __name__ == "__main__":
C for 循环    -> Python 的 for ... in ...
C 字符数组字符串 -> Python str

    你如果已经学过 C，那么学 Python 时重点关注：

    1. 缩进语法
    2. 动态类型
    3. list、tuple、dict、set
    4. 引用和可变/不可变对象
    5. Python 的函数和模块导入方式

    掌握这些后，Python 的基础语法就比较容易上手了。
